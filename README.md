# cryptofeed-rs

Public-first Rust workspace for normalized cryptocurrency exchange market data.

## Crates

- `cryptofeed-core`
- `cryptofeed-ticker`
- `cryptofeed-trade`
- `cryptofeed-orderbook`
- `cryptofeed-rs`

## Development

```bash
cargo check --workspace
cargo test --workspace
cargo fmt --all
cargo clippy --workspace --all-features -- -D warnings
```
