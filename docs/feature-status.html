5 各交易所协议要点（已对 2026-08-04 官方文档核验）

Binancespot · USD-M · COIN-M

  • 现货 bookTicker 无 e/E 字段（u,s,b,B,a,A），解析不依赖事件元数据
  • USD-M 拆双连接：book/depth 走 /public，trade/kline/funding/liquidation 走 /market
  • 混合 feed 自动规划多条物理连接，用户侧仍是一个 FeedHandler
  • 合约 OI 当前仅确认单标的 REST（权重 1）；多标的轮询限流风险使 REST fallback 也暂缓。期权 OI WS 不代表永续/交割合约支持。
  • Index 从 markPrice.i / E 提取；Index 请求共享 @markPrice@1s，Funding 仅永续。深度流间隔：现货 100ms/1000ms，USD-M/币本位 100/250/500ms（部分与全深度同宽）
  • 欧式期权 parser fixture 保留，但 nbstream 端点 404；能力预检当前显式拒绝

Bitgetv3 官方 API

  • 订阅成功响应为控制帧（event: subscribe，无 data），必须先分类再派发
  • books 用 action + seq/pseq 增量连续性；快照序列须落在首个更新区间内
  • 心跳为文本 "ping" 30s / "pong"
  • liquidation 频道按 instType 订阅（无 symbol），1s 聚合推送，逐行解析符号
  • books1 在现货与合约提供 L1 快照；合约 ticker 同时归一化 Funding / OI / Index / MarkPrice，单独订阅任一频道即可使用

Bybitv5

  • 现货 tickers 是 24h 统计、无 BBO —— 项目 Ticker 模型取自 orderbook.1
  • orderbook.1 与 level-50 L2 保持独立路由与事件类型
  • 任何新快照替换本地状态；u=1 视为服务重启快照
  • 衍生品 fundingRate / nextFundingTime 内嵌 tickers.{symbol}；强平使用 allLiquidation.{symbol}（线性/反向端点）；现货不支持 funding/liquidation
  • 未平仓量内嵌于衍生品 tickers 流（无独立频道）
  • orderbook.1 同时产出 BBO Ticker 与 L1Book（带数量）事件
  • 期权走 publicOption 端点；活跃期权经 instruments-info?category=option 目录分页发现（tickers 目录需 baseCoin，2026-08-07 核验）；成交走 publicTrade.{base} 流（行级符号）；iv 字段归一化

OKXv5

  • instType（SPOT/SWAP/FUTURES）贯穿发现、路由、解析全程
  • 蜡烛频道走 /ws/v5/business，其余走 /ws/v5/public，按 URL 拆分
  • 文本 ping/pong；快照替换 + 序列校验 + 全深度 CRC-32 校验和（仅 books）
  • 五家交易所 Funding 均仅永续/Swap（交割 Funding 预检拒绝）；OKX 使用 funding-rate；liquidation-orders 覆盖 SWAP/FUTURES
  • open-interest 频道 3s 推送（oi/oiCcy/oiUsd），覆盖 SWAP/FUTURES
  • index-tickers 推送指数（idxPx/24h 高低开）；现货可显式指定指数，合约从原生 base/quote 映射并向同指数合约分别派发
  • bbo-tbt 为 L1 顶层簿频道（不走 L2 同步路径）；期权（OPTION）经 instruments 目录发现

Gate.iov4

  • 订阅时间戳为秒级且必须新鲜；订阅确认是控制消息
  • quanto_multiplier 非身份字段，允许为 0（含真实 BTC 逆合约记录）
  • 永续按 USDT/BTC 结算分目录；交割过期日与 underlying 需相互印证
  • 衍生品 funding/mark/OI/index 内嵌 futures.tickers 流（无独立频道）；funding 无适用时间字段
  • 永续公共强平 futures.public_liquidates 无需鉴权；有符号的 size 归一化为方向与绝对合约数量，批次逐行匹配；交割强平仍关闭
  • book_ticker 双事件（BBO Ticker + L1Book 带数量）；交割端点实测服务 futures.* 频道（delivery.* 未知，2026-08-07）
